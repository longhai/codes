⚡ TÍNH NĂNG NỔI BẬT

• Lưu trữ dữ liệu Vĩnh Viễn: Danh sách game và thông tin DAT được lưu vĩnh viễn trên trình duyệt giúp tải tức thì. Chỉ cập nhật khi bấm "Cập Nhật Dữ Liệu". Nếu hết lượt API GitHub, trình duyệt sẽ tự khôi phục dữ liệu đã lưu.

• Lọc theo Thể Loại: Trích xuất thẻ <genre> từ file .DAT, hiển thị menu với biểu tượng hình ảnh từ thư mục genre.

• Game Chưa Phân Loại: Hỗ trợ gom nhóm riêng các game không gắn thẻ thể loại trong file .DAT để bạn dễ kiểm tra.

• Game Chính vs Game Con (Clone): Sử dụng dữ liệu .DAT để lọc bớt các bản game clone, hack, giúp danh sách gọn gàng hơn.

• Đồng bộ Google Drive: Đăng nhập Google để sao lưu danh sách Game Yêu Thích lên đám mây, tự động đồng bộ giữa các thiết bị.

• Cài đặt PWA: Hỗ trợ cài ứng dụng trực tiếp lên màn hình chính máy tính hoặc điện thoại để trải nghiệm mượt mà hơn.
