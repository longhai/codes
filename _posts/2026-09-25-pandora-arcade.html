⚡ TÍNH NĂNG NỔI BẬT

• Lọc theo Thể Loại: Trích xuất thẻ <genre> từ file .DAT, hiển thị menu với biểu tượng hình ảnh từ thư mục genre (bao gồm all.png và uncategorized.png).

• Game Chưa Phân Loại: Hỗ trợ gom nhóm riêng các game không gắn thẻ thể loại trong file .DAT để bạn dễ kiểm tra.

• Game Chính vs Game Con (Clone): Sử dụng dữ liệu .DAT để lọc bớt các bản game clone, hack, hoặc phiên bản phụ, giúp danh sách gọn gàng hơn.

• Đồng bộ Google Drive: Đăng nhập Google để sao lưu danh sách Game Yêu Thích lên đám mây, tự động đồng bộ giữa các thiết bị.
